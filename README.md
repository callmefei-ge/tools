# My Tool Sites

A collection of single-purpose tool sites — each one built around a single question, with a working calculator, the formula behind it, reference tables and a plain-language FAQ.

**999 sites and counting**, in English and Chinese, with Spanish, Portuguese, German, French and Japanese editions for the topics that travel well.

Full directory: **https://mytoolmasters.com/tools** — every site, A–Z, on one page.

---

## What you get on each site

No sign-up, no email, no "start your free trial". Open the page, get the number.

- **A calculator that shows its work** — the formula and the units are on the page, not hidden in a script.
- **Reference tables you can keep** — brick counts per m², wire gauges, fee schedules, size charts, cut-off scores.
- **One worked example** — the same inputs, spelled out, so you can sanity-check your own result.
- **A short FAQ** — the follow-up questions people actually ask ("does this include tax?", "why is my number different?").
- **Related tools** — the next question, one click away.

Everything runs in the browser. Results are estimates and are labelled as such.

## About this repository

This repo is the public index for the collection. The sites themselves are static HTML built from configuration files and served from Cloudflare's edge — there is no backend per site, no database per site, and nothing to log in to. That is also why the pages load in well under a second.

## Suggest a calculator

If a calculator is missing, or a number is wrong for your country, open an issue with: the question you're trying to answer, the inputs you have, and the formula or official table you'd expect. Corrections with a source are the fastest to ship.
